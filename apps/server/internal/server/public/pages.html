PRIVACY POLICY

隐私政策

生效及更新日期：2026 年 11 月 21 日

本政策说明 Hako 应用及其 Sora 后端如何处理数据。各项功能按你的配置和操作启用；使用自行部署的实例时，该实例的服务器和访问权限由其管理者控制。

处理哪些数据Google Drive存储与安全撤回与删除联系方式

1. 数据与处理目的

Hako 仅为提供你启用的功能处理相应数据，可能包括：

  • 身份与连接信息：已登记设备的公钥、名称、会话与授权状态，用于识别受信任客户端、保护登录和路由请求。
  • 应用数据：你保存的投资账本、设备查询结果及其他已启用子应用的数据，用于展示、同步、导出和执行你发起的操作。
  • 代码工坊内容：你主动发送的消息、图片、项目及执行信息，通过后端在客户端与已授权电脑之间传递。电脑上的工坊及所选模型服务会按其各自配置处理内容。
  • 运行记录：操作结果、故障诊断及服务器访问记录可能包含时间、IP 地址、请求路径和设备标识，用于排障、执行历史和安全管理。访问日志的来源与保留期由实例配置决定。

这些页面不加载第三方广告、分析脚本或追踪像素。后台使用会话 Cookie 来维持管理登录。

2. Google Drive 数据与授权

Google Drive 备份是可选功能，不连接 Google Drive 也可以使用其他功能。授权在 Google 提供的页面中完成，Hako 不接收你的 Google 密码。

权限及访问范围

Hako 仅申请 https://www.googleapis.com/auth/drive.file，用于创建备份目录、上传或更新备份文件，并查询 Hako 已获授权文件的名称、ID、大小、校验值等必要元数据。不申请整个云端硬盘的访问权限，也不主动读取与备份无关的个人文件。

备份内容与传输

当前投资记账备份包含服务端已保存的账本 CSV 与 SQLite 建表语句，并以 ZIP 提交。客户端从你配置的 Hako 服务端导出账本，再直接通过 Google Drive API 上传到你配置的目录；校验文件大小与校验值。Google 授权令牌和 Drive 上传流量不经 Hako 后端转发。

令牌、配置与结果

用于访问 Google 的访问令牌及刷新令牌保存在 iOS 系统钥匙串中。连接名称、OAuth Client ID、目录配置和近期备份结果保存在客户端本机。文件与元数据留存在你授权的 Google Drive 中，受你的账号及共享权限控制。

使用与共享限制

Google 用户数据只用于你选择的备份、文件管理和完整性校验，不出售，不用于广告、用户画像，也不用于训练通用人工智能或机器学习模型。不因连接了 Google Drive 就自动把云端硬盘内容交给代码工坊或模型服务。数据只按你的备份操作传给 Google；另行启用 WebDAV 等目的地时，同一份应用备份也会发送到你配置的相应目的地。

Hako 对从 Google API 获取的信息的使用和转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

Hako's use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. 存储、第三方与安全

应用配置和本机缓存保存在你的设备上；服务端数据保存在所连接的 Sora 实例中；工坊任务及其历史主要保存在执行电脑上。服务和备份目的地的运营方可能处理传输或存储的数据，其自身条款和隐私政策也适用。

Hako 使用系统钥匙串保护敏感凭据，并使用配置的安全传输与身份验证机制。备份 ZIP 本身不额外加密；请妥善管理备份目的地、账号与共享权限。没有任何传输或存储方式能保证绝对安全。

本机执行记录及服务器记录依功能和实例配置保留；云端备份会保留到你手动删除或目的地的保留规则生效。当前备份功能不自动删除历史备份。

4. 撤回授权与删除数据

  • 停止备份：停用目的地或停止相关快捷指令自动化，即可停止之后的备份。
  • 移除本机授权：在 Hako 的 Google Drive 连接管理中断开连接，移除该连接的本机凭据。移除仍被目的地使用的连接前，需要先修改或移除相应目的地。
  • 撤销 Google 授权：在 Google 账号的第三方应用访问权限中移除 Hako。仅在 App 中断开连接，不等于撤销 Google 账号中的授权。
  • 删除已上传文件：在 Google Drive 或对应 WebDAV 服务中删除备份，并按需要清空回收站。断开连接或移除目的地不会自动删除远端文件。
  • 服务端数据：通过相关应用功能管理可删除的数据，或联系你的实例管理者。联系本服务维护者申请删除时，我们会先核验请求与所涉数据的关联。

撤回授权不改变撤回前已按你的请求完成的处理；第三方备份、副本和法律要求保留的记录需按适用规则分别处理。

5. 政策更新

当功能或数据处理方式发生变化时，我们会更新本页及更新日期。涉及 Google 数据用途的变化应先在应用中明确告知，并在需要时重新取得授权。

6. 联系方式

Hako 项目与本服务维护者的联系邮箱为 {{.Email}}。如需咨询、报告隐私问题或申请删除数据，请说明所用实例地址及请求范围。请勿通过邮件发送密码、令牌、私钥或完整备份包。
