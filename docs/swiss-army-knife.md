# 瑞士军刀

首页「开发工具」中的实用小工具集合。

## 二维码扫描器

- 打开「瑞士军刀 → 二维码扫描器」，允许相机权限后，将二维码放入镜头中。
- 取景使用后置相机、1080p 和连续自动对焦；支持多摄设备按场景切换镜头。可点按二维码位置对焦，双指缩放小二维码。
- 识别成功后停止取景，显示二维码原始文本，支持选择文本或点击「复制文本」复制全部内容。
- 点击「重新扫描」读取下一张二维码；离开扫描页或应用进入后台时停止取景。
- 未获相机权限时显示原因，可前往系统设置授权后重试。
- 识别和复制均在本机完成，不上传扫描内容，不自动打开二维码中的链接。

相机二维码识别由共享 UI 组件 `HakoQRCodeScanner` 提供，网页登录扫码复用同一组件；各入口自行处理扫描结果。
