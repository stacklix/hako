# 瑞士军刀

首页「开发工具」中的实用小工具集合。

## 随机字符串

- 打开「瑞士军刀 → 随机字符串」，输入 1–1024 位的整数长度（默认 16 位）。
- 数字、小写字母、大写字母和标点符号可独立开关；默认包含数字和大小写字母，不包含标点符号。
- 至少选择一种字符类型，结果保证每种勾选类型至少出现一次，因此长度不能小于勾选类型数量。无效配置会提示原因并禁用生成。
- 标点符号为 32 个英文半角 ASCII 符号，不包含空格。使用系统随机数在本机生成，不上传或保存历史记录。
- 点击「生成字符串」或「重新生成」更新结果；支持选择文本或点击「复制字符串」复制全部内容。更改选项后，已生成结果保留，直到再次生成。

## 二维码扫描器

- 打开「瑞士军刀 → 二维码扫描器」，允许相机权限后，将二维码放入镜头中。
- 取景使用后置相机、1080p 和连续自动对焦；支持多摄设备按场景切换镜头。可点按二维码位置对焦，双指缩放小二维码。
- 识别成功后停止取景，显示二维码原始文本，支持选择文本或点击「复制文本」复制全部内容。
- 点击「重新扫描」读取下一张二维码；离开扫描页或应用进入后台时停止取景。
- 未获相机权限时显示原因，可前往系统设置授权后重试。
- 识别和复制均在本机完成，不上传扫描内容，不自动打开二维码中的链接。

相机二维码识别由共享 UI 组件 `HakoQRCodeScanner` 提供，网页登录扫码复用同一组件；各入口自行处理扫描结果。
