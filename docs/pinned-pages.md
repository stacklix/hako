# 固定页面（Pin）

起手区域为 App 窗口右侧 32pt，覆盖窗口全高，支持稍带斜向的左滑。导航栏和底部标签区域同样可以起手；系统状态栏、控制中心和 Home 手势仍由 iOS 处理。普通上下滚动不会展开 Pin。

从屏幕右边缘向左拖动打开 Pin 列表，在任意页面及 Sheet 中均可使用。侧栏位置和背景遮罩随手指进度变化，反向拖动可以收回；展开后向右拖动也可折叠。松手后根据展开幅度与滑动速度完成展开或收起，系统取消手势时恢复原状态。「管理」模式保留列表原生移除和排序手势，可拖动标题区域、使用关闭按钮或遮罩收起侧栏。

选择固定项会以 Sheet 打开，左上角「进入」切换到子应用的完整页面，右上角关闭或下滑则回到原页面。进入完整页面前会保护仍有未保存修改的 Sheet。

当前只支持代码工坊会话和容器详情。两者均通过右上角「更多」菜单加入 Pin；已固定时同一菜单提供「取消固定」。列表中的「管理」支持移除和排序，首页不提供固定入口。

## 当前可固定页面清单

按实际可见的固定入口核对：

| 页面 | 可固定范围 | 入口 |
| --- | --- | --- |
| 代码工坊会话详情 | 已生成有效会话 ID 的具体会话；未建立的新会话不提供固定操作 | 右上角「更多会话功能」菜单 |
| 容器详情 | 每个具体容器的概览、日志、文件、操作四个页签，绑定当前 Arcane 连接和环境 | 右上角「更多容器功能」菜单 |

所有子应用首页、青龙面板、投资记账、云服务器等均不提供固定入口或页面恢复路由。撤回路由的记录不在 Pin 列表中显示。

其他下级页面没有独立固定入口，包括设备详情、投资标的详情、青龙单个任务或脚本编辑器、容器文件编辑器与终端等。容器详情恢复所选页签及上表明确列出的业务对象，不恢复搜索条件、滚动位置或文件浏览目录。

## 子应用接口

主应用维护 `HakoPinStore.shared`。子应用调用 `pin(_:)` 加入或更新页面，调用 `remove(_:)` 取消固定；也可以复用 `HakoPinButton(page:)` 提供菜单操作。

`HakoPinnedPage` 包含应用标识、路由名、稳定业务 key、展示标题、副标题、SF Symbol 和字符串参数。相同应用、路由、key 重复固定时只更新展示信息，不重复添加，也不改变已有顺序。账号、实例等业务范围应进入 key，并在打开页面时再次验证。参数只保存恢复页面所需的标识，不保存密码、Token、密钥或临时会话认证信息。

子应用通过自己的 Contributor 向 `HakoPinRegistry` 注册路由和延迟创建页面的回调。统一在 `HakoApplications.pins` 汇总注册；主应用不解释子应用业务参数。普通页面和 Sheet 使用同一回调，Sheet 通过环境值 `hakoPinPreview` 告知页面隐藏重复的导航操作。异步恢复失败应显示可理解的原因，并允许重试；原连接或账号不匹配时不得自动打开其他对象。

列表保存在本机设置中，重启后保留，不包含预置或演示固定项。列表只展示当前已注册路由的固定项；排序和移除操作只作用于可见记录。
