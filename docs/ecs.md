# 阿里云 ECS

iOS 首页「云服务器」直接调用阿里云 ECS API，当前保存一组地域、实例和 RAM 凭据。无需 Hako 服务端、ECS 公网 IP、SLS、VPC 流日志、OSS 或自建监控接口；不安装第三方采集器，不修改防火墙，不创建常驻进程或周期任务。

## 配置

打开「云服务器 → 右上角滑杆」填写连接名称、地域 ID（如 `cn-hangzhou`）、实例 ID（`i-...`）、Linux 用户名、RAM AccessKey ID / Secret。STS 凭据同时填写临时 AccessKey ID、Secret 和 Token；过期后更新整组凭据。点击「测试连接」只查询实例信息，点击右上角勾号才保存。

凭据保存在独立 Keychain 项 `me.stackli.hako.ecs`，仅本机解锁时可访问，不同步到其他设备、不上传 Hako 后端。ECS RPC 使用 HTTPS POST 和 HMAC-SHA1 签名，凭据不进入请求 URL；禁止自动重定向，不输出阿里云原始错误正文或签名材料。

## 实例前提

- 运行中的 Linux ECS；实例信息、基础监控使用官方接口。
- 已有阿里云云助手 Agent 在线。终端还需在阿里云控制台开启会话管理，Agent 版本需满足服务要求。
- 系统快照使用实例**已有 Python 3 标准库**读取 `/proc` 与文件系统，查询端口和连接还使用已有 `ss`（iproute2）。缺少依赖时报告查询错误，Hako 不会自动安装软件。
- 配置的 Linux 用户存在且具备所需读取权限。无法读取其他用户的 PID、磁盘 I/O 或可执行文件时隐藏对应字段，不将缺失值填成零。

RAM 身份至少需要以下实际使用的操作权限，授权范围与条件以各 API 的 RAM 授权说明为准；不要用主账号或直接套用 ECS 全权限：

| 用途 | API |
| --- | --- |
| 实例信息 | `ecs:DescribeInstances` |
| 分钟监控 | `ecs:DescribeInstanceMonitorData` |
| 读取系统快照 | `ecs:RunCommand`、`ecs:DescribeInvocationResults`、`ecs:StopInvocation` |
| 终端 | `ecs:StartTerminalSession`、`ecs:EndTerminalSession` |

注意 `RunCommand` 是命令执行权限，并非普通只读监控权限；Hako 发出的采样脚本只读取系统信息，但 RAM 身份拥有的权限边界仍按阿里云策略执行。

## 页面与数据口径

- **概览**：最顶部一排三个仪表盘依次展示 CPU、内存和磁盘使用率，数据未到时保留仪表盘框架并显示 `—`，不再单独展示磁盘 section 或磁盘读写速度。CPU 优先用 `/proc/stat` 总 CPU 计数约 1 秒差值，按整机 0–100% 计算，不重复计入 guest 字段；采样不可用时使用最近五分钟内最新有效的云监控 CPU 点，跳过末尾缺失值且保留真实的 0%。仪表盘下方区分短时采样和云监控的 1 分钟均值。内存使用、挂载点使用量、负载、内核、架构和运行时长来自云助手一次性查询。内存已用为 `MemTotal - MemAvailable`；磁盘仪表盘用去重后文件系统的总已用 / 总容量计算加权使用率，汇总在输出截断前完成。磁盘按文件系统实际块数统计，不把云盘容量当作使用量。同一文件系统按设备去重，优先展示根挂载而非 bind 别名；过滤 Docker / containerd 的容器 overlay，只有系统根目录自身为 overlay 时保留该根目录。
- **网络**：首行四个数字依次为上行速率、下行速率、主动连接数、被动连接数；点击各自的标题或数字区域，分别进入对应方向的连接详情。流量只读取 `eth0` 约 1 秒的计数差；没有该网卡时显示缺失，不回退到 Docker 网桥或其他网卡。累计来自 `/proc/net/dev`。实例内网最近一小时趋势位于监听端口上方，来自阿里云基础监控，`IntranetRX/TX` 周期内 kbits 乘 `1000 / 8 / 60` 转为 Byte/s。监听端口默认折叠，可展开，只展示主机网络中的监听项，按「协议＋端口」合并 IPv4 / IPv6 及多 IP；不把容器内部监听当作主机端口，host-network 容器则属于主机网络。详情保留监听 IP、PID 和进程。该列表不判断公网可达性，也不枚举仅通过 NAT 发布且没有主机监听套接字的端口。
  遇到主机 `docker-proxy` 时，读取该 PID 的代理参数，并通过本机 `/var/run/docker.sock` 的只读 Docker Engine API 匹配容器名称；同时核对协议、主机 IP / 端口和容器 IP / 端口，唯一匹配后在端口、连接及进程列表显示 `docker:<容器名>`，保留原 PID。每次快照只查询一次容器列表；不读取容器环境变量，不跟随远端 Docker context，不修改 Docker 配置或权限。无权读取、Docker 不可用、映射不明确或 PID 已变化时保留 `docker-proxy`。
  连接数统计采样时仍保持的 TCP 连接，不是累计 HTTP 请求数，也不包含 HTTP/3 的 UDP 会话。除主机网络外，按 `/proc/<pid>/ns/net` 去重，并使用已有 `nsenter` 和主机的 `ss` 读取有权限访问的独立网络命名空间；host-network 容器不会重复读取。容器补读最多 32 个命名空间、共 8 秒，缺少工具、权限不足或超过预算会提示统计不完整。方向只匹配同一命名空间内的监听地址和端口，处理带接口标识的 IPv4 与 `v6only` 双栈信息；监听关闭或主动复用监听端口时仍可能误判。包含本机内部连接，代理两侧独立计数，不代表独立访客数。总数在输出截断前计算；监听记录优先保留，截断时提示连接与端口详情可能不完整。
- **进程**：列表标题右侧的原生菜单选择 CPU / 内存从高到低排序；标题下方保留一行轻量分类筛选，仅选中项显示底色，控件不再单独包成卡片。分类后同步更新进程数量，左侧显示名称、PID 和用户，右侧同一列上下显示 CPU、内存；缺少 CPU 采样时显示 `—`。列表仅返回 PID、名称、用户、分类、CPU 和 RSS，父进程、UID、线程数、运行时长、分类依据、可执行文件路径和磁盘 I/O 进入详情后仅针对该 PID 读取，加载前不显示虚构的详情值。CPU 在两次采样间计算，按单核 100% 计；多线程可能超过 100%。相同 PID 的启动时间变化时不计算差值，防止 PID 复用造成错误。内存为 RSS；I/O 为内核 `read_bytes/write_bytes` 累计计数。系统 / 用户类型是按内核线程标记、已知基础服务名称、用户会话与 UID 的推断，无法确认的保留「未分类」，不会将所有 root 进程归为系统。
- **终端**：SwiftTerm 原生输入，不提供单独命令输入框，也不显示「已连接 / 断开」状态栏。进入云服务器时后台预建终端会话，终端视图提前挂载；未就绪时显示静态连接文字并可取消，不显示加载动画。连接异常、握手超时或远端结束会话后，遮罩显示错误和「重新连接」按钮，旧会话清理期间禁用重连。遮罩期间关闭键盘、屏蔽终端交互并隐藏快捷键，连接成功后移除遮罩。阿里云 AXT 二进制协议处理窗口尺寸、45 秒空输入心跳、序列号和同一通道同步；断线后不自动重连或重放命令。首次握手 25 秒超时。截图预览的 `.inactive` 和切换到后台的 `.background` 均不主动关闭连接或结束云端会话；截图后或窗口重新激活时恢复输入焦点，返回前台另做一次最长 5 秒的 WebSocket Ping 探测，仍可用则继续原会话，失效才显示重新连接。iOS 可能挂起后台 App，心跳和读写不能保证持续执行，因此保留会话不等于保证后台不断线。切换 Tab 保留会话与输出，只有终端 Tab 可获取键盘焦点；离开云服务器页面或打开配置时关闭会话并调用 `EndTerminalSession`。创建会话期间退出仍消费迟到响应并清理；清理失败明确提示在阿里云控制台核对。

进入云服务器、关闭连接设置或返回前台时，实例信息、基础监控及概览 / 网络 / 进程快照按资源独立并行加载，终端会话同时准备。页面先渲染分组、筛选和 `—` 占位，后台加载不显示转圈动画；某个请求缓慢或失败不会阻塞其他数据出现。切换 Tab 使用已加载数据，不取消其他页查询。页面可见、App 活跃且未打开设置时，三个仪表盘共用的概览快照独立每 3 秒刷新（包含请求耗时；慢请求完成前不叠加新请求），其余数据每轮完成后约 30 秒刷新，访问统计独立每 60 秒刷新；支持下拉刷新当前页。相同资源的进行中请求合并，退出页面、打开设置或后台时取消数据查询。各资源独立保留错误，查询失败保留旧数据及快照时间，新配置保存后清空旧实例数据。

进程筛选包含「全部 / 系统 / 用户 / 云服务 / 未分类」。Docker 容器按 cgroup v1 / v2 的完整容器 ID 或 `docker-<ID>.scope` 识别，包含 root、host-network 和 rootless 容器，容器身份优先于进程名称及 UID，归入「用户」。已匹配到本机容器的 Docker 端口代理也归入「用户」；未能确认映射时保留原分类。主机上的 `dockerd`、`containerd` 和 `containerd-shim` 属于「系统」，不会仅凭路径包含 docker 就当作容器。阿里云云助手、云安全中心及云监控按已知进程名称或服务单元归入「云服务」，兼容 Linux 进程名的 15 字节截断；不使用任意 aliyun 子串匹配。详情展示具体分类依据；列表仍只返回原有六个精简字段，识别不依赖新增详情查询。

采集脚本以 raw DEFLATE 压缩后通过 Base64 传输，由实例已有 Python 3 标准库解压执行；发送前校验编码后的完整命令小于 24,000 字节。

云助手命令设置 `KeepCommand=false`、45 秒执行超时、`TerminationMode=ProcessTree`，不创建定时任务；取消和等待超时会尝试停止整个查询进程树。每次返回结果预算 20,000 字节，低于云助手 24 KiB 截断阈值。进程列表按 PID 游标自动分批读取，全部批次成功后才更新页面，再对完整返回列表进行 CPU / 内存排序和分类；后续批次失败或取消时保留旧列表，不把部分结果当作完整清单。分批期间进程可能启动或退出，各批次独立采样，快照时间为首批采样时间；无法读取基本信息或采样期间已退出的进程会跳过。不在实例上缓存列表或创建常驻采集器。网络等其他快照结果过多时仍缩短记录并标记部分结果。单个进程详情独立查询。

终端首个输出序号允许 0 或 1，后续重复包仍去重。原生视图使用非零初始尺寸并跳过临时过小布局；只在主题变化时更新解析后的颜色。键盘焦点在遮罩移除且视图进入窗口后恢复。当前会话输出仅在内存保留最近 1 MiB，视图暂未挂载或被重建时恢复显示，视图销毁不直接结束屏幕拥有的会话；新会话清空缓冲，不重放输入。日志只记录首包序号和字节数，不记录终端输出内容。

当前界面不显示端口 / 进程完整网络流量、流量排序、未采集历史、秒级基础监控等不可提供的项目。没有演示值或「不支持」功能占位。

## Caddy 网站访问统计

云服务器保留概览、网络、进程、终端四个 Tab。概览仪表盘下方的「网站访问」卡片独立读取 Hako 服务端的 Caddy 统计，展示全部域名近 24 小时 HTTP 请求数、404 数量和占比，以及最近日志扫描时间。点击进入「访问统计」详情，选择全部域名或单域名、近 1 / 3 / 6 / 12 / 24 / 72 / 168 小时。1 / 3 / 6 / 12 / 24 小时按小时展示趋势，72 / 168 小时按服务端时区汇总为天。日志统计包含爬虫请求，来源 IP 不等于独立访客。

访问统计默认使用 App 当前已配置并登录的 Hako 服务器，自动展示全部域名（包括后续新增域名），无需单独配置数据来源或关联域名。详情页的域名筛选只影响查看范围，不控制采集。统计范围为该 Hako 服务端采集的全部 Caddy 日志，不按 ECS 实例隔离。无需额外的服务、付费平台或 ECS 采集程序；Hako 服务端须已配置现有 Caddy 日志采集，并升级到包含 App 只读路由的版本。

全部域名展示域名请求排行。单域名展示 404 页面、URL 和来源 IP Top 10；404 页面可查看对应 IP / User-Agent，来源 IP 可查看对应 URL / User-Agent。趋势使用蓝色柱状表示 HTTP 请求、橙色折线表示 404；全部域名和单域名均可点击柱子，高亮并悬浮显示对应小时或日期的请求数与 404 数量，松手后保留选中。单域名小时趋势还可选择时点查看该小时排行；天趋势不提供小时下钻。不合并各域名的 Top 10，不显示后台未采集的流量、延迟、UV 或 5xx。汇总与排行使用同一固定时间窗口；零请求时 404 占比为 0。小时记录被截断时隐藏趋势并提示缩小范围，完整汇总仍展示。

进入页面、返回前台、关闭设置后自动加载；可见且前台时每 60 秒刷新，也支持下拉刷新。请求失败保留原数据与扫描时间，显示错误。扫描结束时间也会在失败时更新：后端报告错误时显示「日志扫描异常，统计可能不完整」，详情页「数据状态 → 查看扫描错误」可展开实际错误；没有错误但超过 3 个周期（至少 3 分钟）未结束扫描时才显示延迟。首次扫描前区分等待与扫描中，不显示延迟警告。请求复用 Console 的 DPoP 登录、令牌刷新和禁止重定向的 HTTPS 通道，不保存第二套密码或 Token。统计数据不写入本地诊断日志。

`ECSAccessTests.swift` 覆盖域名隔离、完整汇总与缺失小时补零、服务端时区与非整点 UTC 偏移、扫描新鲜度、固定时间窗口参数编码，以及嵌套排行榜解码；macOS CI 在归档前执行。

## 验证

Windows 可运行所有 Python 测试：

```sh
python -m unittest discover -s apps/ios/Tests -p 'test_*.py'
```

`test_ecs_snapshot.py` 覆盖含括号进程名、PID 复用、root 分类、权限缺失、精简列表字段及不读取详情、单 PID 详情采样、列表游标、多批次完整返回与字节预算、网卡计数重置、IPv6、监听端点匹配、连接方向推断、截断前连接计数、监听记录优先保留、eth0 限定、容器网络去重及权限不足提示、容器 overlay 过滤、磁盘 bind 去重和输出预算；在 Linux 上额外读取真实 `/proc` 验证概览、网络和当前进程。Linux CI 执行同一套测试。`ECSTests.swift` 另覆盖精简记录解码、进程分页合并、无效游标、重复 PID、分页失败和取消。`ECSLoadingTests.swift` 覆盖并行预加载、跨页请求互不取消、部分失败、立即离开再进入、相同资源请求合并，以及仪表盘独立轮询、慢请求不重叠和取消后停止。`ECSNetworkTests.swift` 覆盖端口解析、TCP / UDP 与双栈监听合并、连接分组、完整总数与截断列表分离、缺失值及速率单位，macOS CI 执行。

macOS CI 在归档前对 ECS 非 UI 源码进行类型检查，并运行 `ECSTests.swift`：官方签名向量、百分号编码、STS 与 POST 参数、原始错误脱敏、监控单位转换、缺失字段、AXT 帧边界、0 / 1 首包序号、乱序同步、重复输出与输入确认，以及视图挂载前输出、渲染器替换、输出缓冲上限、新会话清空和连接探测成功 / 超时 / 重复回调。

Windows 不运行 iOS 编译、签名或安装；上述脚本测试不代表已经通过真机与真实 ECS 验证。真机还需验证输入法、粘贴、方向键、终端 resize、切换页面 / 前后台清理、权限不足、STS 过期及实际 RAM 策略。没有真实阿里云凭据时不尝试连接用户实例。
