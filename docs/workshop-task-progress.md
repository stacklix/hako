# 后台任务元数据

代码工坊会话不展示构建进度，也不读取或轮询 `tasks.list`。构建命令与后台监控仍由应用外的工具执行。

Agent 保留只读的 `tasks.list {threadId}` 元数据接口，仅返回指定会话的有界数据。接口不执行记录中的命令，也不增加服务端业务路由。

用户级工具将任务记录写入 `$CODEX_HOME/task-progress/<会话 UUID>/<任务 ID>.json`，未配置 CODEX_HOME 时使用用户 `.codex` 目录。记录包含任务名称、项目、平台、真实阶段、状态、时间、可选的摘要与发布信息。公共记录不含命令、凭据或原始日志，worker 配置与日志位于独立 `_workers` 子目录，不返回客户端。

记录校验与会话隔离由 Agent 负责；后台任务不依赖会话页面是否打开。
