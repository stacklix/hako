# 青龙面板

Hako iOS 首页的「青龙面板」直接连接已有青龙面板，不依赖 Hako 服务端。模块源码位于 `apps/ios/Hako/Qinglong/`，使用主应用提供的 `HTTPTransport`、`SecretStorage` 和日志服务，不引用其他子应用的业务代码。

## 配置连接

1. 在青龙「系统设置 → 应用设置」创建应用，按使用范围授予 `crons`、`scripts`、`subscriptions`、`envs`、`configs`、`dependencies`、`logs` 权限。
2. 打开 Hako → 青龙面板 → 右上角滑杆图标 → 设置 → 添加面板，填写面板地址、Client ID 和 Client Secret。两个凭据各占一行，始终显示字段名。
3. 需要自定义请求头时开启「添加自定义请求头」。名称和值初始为空，不带占位符；可添加多条，应用于获取 Token 和后续全部接口请求。禁止覆盖 Authorization、Host、Content-Type 等内置请求头，拒绝重复名称和换行值。
4. 测试连接仅验证应用凭据，不要求系统管理权限。保存后在「更多 → 应用权限」逐项检测读取权限。

支持多个面板，在设置中的「面板实例」直接点击切换，当前实例显示勾选；未选中实例没有跳转箭头，切换后保留设置页面。地址可包含部署前缀，也可填写以 `/open` 结尾的地址；保存时统一处理，后续追加 `/open/...`。HTTP 需显式开启。连接、密钥、请求头和当前选择一并存入独立 Keychain namespace，不保存在 UserDefaults 或 GitHub。读取配置失败时不覆盖原配置。

## 功能

- 底部四个 Tab：任务、脚本、订阅、更多。样式按运动记录风格的已确认原型实现：28 点标题、列表标题右侧的新建按钮、标签在上数字在下的统计区、页面内搜索、共用白色圆角面板的分隔列表和紧凑状态菜单。实例切换统一放在设置内。更多菜单通过原生 NavigationStack 进入独立页面，页面底部保留 Tab；设置入口保留原生滑杆。新增、编辑、详情和日志使用系统 sheet，内部为原生导航栏与分组 Form，保存／取消在系统工具栏。环境变量与任务共用分组字段样式，变量值使用密码输入，启用状态使用原生开关。
- 任务：完整分页读取、搜索、运行／失败／禁用筛选、创建和编辑命令与 Cron、启停、启用／禁用、确认删除、最近执行日志。
- 脚本：递归读取文件树并按文件列出，可按文件名和目录搜索；新建、查看、编辑、保存、确认删除，运行已保存版本和按返回 PID 停止调试。
- 订阅：查看、创建公开 Git 仓库订阅、编辑名称／地址／别名／分支／筛选关键词／Cron、拉取、停止、启用／禁用、删除、最近日志。编辑已有订阅保留其私有仓库凭据、间隔计划、钩子等未展示字段。
- 更多：环境变量增删改查与启用／禁用，变量值默认遮蔽；查看与编辑配置文件；只读依赖列表和日志文件；连接管理与权限检测。

Cron 按青龙面板自身的时区解释；任务状态使用接口实际的运行、空闲、排队和禁用状态，不把「空闲」解释为上次执行成功。运行／停止请求成功只表示接口接受，需继续查看状态及日志确认结果。

任务列表、详情与日志内的运行／停止使用原生确认弹窗；确认只关闭弹窗，保留原页面及日志内容，刷新实际状态并就地显示提交结果。环境变量保存内容与启用状态分别使用面板接口；状态更新失败会保留已保存的变量编号及编辑草稿，重试使用更新接口，避免重复新增。面板未返回新增编号时禁用继续保存并提示回到列表核对。

任务与订阅列表仅在前台可见时每 10 秒刷新，进入详情、离开子应用或打开设置／新建表单即停止列表轮询；任务详情可见时单独每 10 秒刷新状态，打开编辑或日志即暂停。日志页可见时每 5 秒刷新最近记录，每 10 秒更新任务状态。日志请求使用 `tail` 和 256 KiB 限额，旧面板是否遵循限额取决于版本。脚本、变量等按进入页面及手动刷新读取。任务成功／失败仅依据真实实例的状态和退出码；面板不支持实例接口时显示空闲或结果未知，失败汇总以横线表示，不伪造成功或失败。切换连接清空内存缓存，丢弃旧请求结果；旧编辑器不能向新连接写入。

## 接口与边界

使用 [青龙官方 OpenAPI](https://qinglong.online/api/index)：`GET /open/auth/token` 交换令牌，令牌按 `expiration` 秒级时间戳缓存在内存。401 清空缓存，下次显式请求重新获取；每个响应同时检查 HTTP 状态与业务 `code`。所有请求禁用 Cookie、磁盘缓存和自动重定向。网络错误、5xx 或响应异常的写请求不自动重试，提示先核对远端状态。

脚本调试接口 `PUT /open/scripts/run` 必须提交实际 `content`，省略会执行空内容。应用先读取已保存版本再提交，编辑器中的未保存草稿不参与运行。该接口在同目录使用临时脚本，不等同于运行原定时任务；目前不接入其面板 WebSocket 调试输出，提示在面板查看。定时任务执行及日志通过任务页操作。

文件保存前会重新读取并比较原内容，发现远端变更保留本地草稿并中止保存。新建前检查文件名是否已存在。这是客户端预检查，普通保存接口没有原子版本条件，不能保证预检查与写入之间不存在并发修改。编辑器关闭时提示放弃未保存修改。Client ID、Client Secret 各占一行，自定义 Header 无默认值或占位符。

未实现系统升级、重启、用户管理、依赖安装及脚本历史恢复。接口不足或权限不足显示实际错误，不退回管理员登录、不绕过面板权限。没有预置演示连接或业务记录。

应用日志新增「青龙」来源，仅记录模块、方法、状态和耗时，不记录 HTTP 正文、文件内容、认证头、凭据或获取令牌的查询地址。

## 验证

`apps/ios/Tests/QinglongTests.swift` 使用 URLProtocol 模拟面板，覆盖地址与 Header 校验、树形文件列表、订阅编辑字段保留、Token 缓存与失效、Header 传递、任务分页、业务错误、结果不确定的写操作不重试、空文本保存。已接入 iOS CI。

```sh
cd apps/ios
swiftc Hako/HTTPTransport.swift Hako/Logging/HakoLog.swift Hako/Qinglong/QinglongProtocol.swift Hako/Qinglong/QinglongClient.swift Tests/QinglongTests.swift -o /tmp/hako-qinglong-tests
/tmp/hako-qinglong-tests
```

首次真实面板验收需用户自己的面板地址和应用凭据。建议验证：无权限模块的提示；切换连接；任务运行和日志；脚本空内容保存、远端冲突保护与调试；变量遮蔽；订阅编辑不丢失原设置；前后台轮询停止。
