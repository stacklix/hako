# 路由器子应用

Hako iOS 的「IT工具 → 路由器」管理 TP-LINK 路由器，首个适配目标为 TL-XDR5480 易展 Turbo 版。连接地址与管理员密码在右上角滑杆设置中填写；验证成功后使用独立系统钥匙串命名空间保存。

连接方式自动选择，无需手动切换。每次刷新核心状态或配置写入前的状态检查，通过共享 `LocalNetworkService` 刷新并读取主应用的 `isLocal`：内网直连，否则走 [Sora HTTP 代理](http-proxy.md)。网络环境完全由主应用「设置 → 网络配置」中登记的 Wi-Fi 和现有网络服务判断，路由器子应用不另行探测主页、SSID 或网络接口。未识别 Wi-Fi、外网及未登记 Wi-Fi 均使用代理。切换链路会清除内存会话并重新登录，页头显示实际使用的连接方式。

外网使用前先登录 Sora，在主应用「设置 → HTTP 代理」选择家中在线且能访问路由器的 Agent。路由器地址仍为 `192.168.0.1` 等私有地址，HTTP 端口为 80，链路为手机 → Sora → Agent → 路由器。所有登录、查询、写入及回查复用相同代理机制；代理失败时明确报错，不自动回退直连。写请求不跨链路自动重发；需要核对结果时由用户刷新，重新判断连接。无需将路由器管理端口开放到公网。

## 页面与功能

- **概览**：IPv4/IPv6 连接、当前上下行速率、在线设备数、绑定数、Mesh 节点数、活跃设备与常用入口。
- **设备**：在线、离线、禁用设备筛选；名称、IP、MAC 搜索；详情显示地址、接入方式、SSID、信号与连接时长。支持重命名、上网权限、KB/s 限速及 IP/MAC 绑定增删改。
- **网络**：主 Wi-Fi 与双频合一现有配置的修改；2.4 GHz 访客网络、开放时长与局域网访问权限；无线定时计划。只读查看 DHCP 配置与租约、IPv6、端口协商速率及 Mesh 节点。
- **工具**：UPnP 开关与动态映射、端口转发增删改、网络唤醒、定时重启计划、手动重启、系统日志。DDNS、DMZ、双 WAN、IPTV、聚合、接入名单及复杂上网规则当前提供只读查看；其高级配置使用原厂管理页。

网络唤醒被接受不代表设备已启动；需刷新设备列表核对。重启被接受后会等待用户重新连接并刷新，不把请求响应描述为启动或恢复成功。IP/MAC 绑定不承诺等同于静态 DHCP 租约，分配与生效行为以固件为准。

## 写入规则

- 每次提交前重新读取配置，检查原记录及正在修改的字段未被远端改变。绑定使用当前 LAN 网段校验，排除网关、网络和广播地址、重复绑定及其他在线设备占用的 IP。
- 新增绑定显式分配未使用的 `user_bind_<编号>`；AP 或无线中继模式下禁止绑定管理。端口转发同样检查路由模式与外部端口冲突。
- 配置写入后重新读取并比较目标字段。超时、异常响应或结果不一致时进入待核对状态，刷新成功前禁用写入；不自动重发写请求。
- 无线和重启操作在 App 内单独确认。不会自动关闭硬件加速来绕过限速限制。
- 定时计划按路由器本地时间执行，最多 4 条；新增后单独开启总开关，开启前检查时间同步状态。

## 协议与验证

协议依据目标设备原厂网页脚本和已安装插件源码，包括登录与数据请求、IP/MAC 绑定、访客网络、无线定时、端口转发、网络唤醒、定时清理及 UPnP。

`POST /` 使用 `method=do` 与 `login.password` 登录；密码按固件 `orgAuthPwd/securityEncode` 编码。后续访问 `/stok=<会话>/ds`。会话可能包含符号，须按 `encodeURIComponent` 编码为路径组件；请求 JSON 中的字符串值也采用同一编码规则。

路由器侧 HTTP 协议未加密，仅接受私有 IPv4 地址，禁用系统代理与 HTTP 重定向。直连由手机访问；Sora 模式通过显式 `X-Proxy` 请求头交给共享传输层，由所选 Agent 访问。密码保存在本机钥匙串，代理模式下登录数据、会话与路由器响应经 Sora 和 Agent 转发。HTTP 日志隐藏请求和响应正文，同时隐藏原始及编码后的会话值；通用代理封装同样不记录正文。
